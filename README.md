# DompetKu - Expense Tracker

Aplikasi pencatat keuangan sederhana menggunakan React Native + Expo.

## Features
- Tambah pemasukan
- Tambah pengeluaran
- Hitung total saldo otomatis
- History transaksi
- Warna berbeda untuk pemasukan & pengeluaran
